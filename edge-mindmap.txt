【作品简介】
Edge Mindmap 是一个基于阿里云 ESA 边缘计算的高性能在线思维导图编辑器。
本项目由阿里云ESA提供加速、计算和保护。

========================================
项目介绍
========================================

【技术探索】

充分利用ESA的完整生态
   
  ✓ ESA Pages
    - 整个前端应用部署在ESA Pages上
    - 享受全球边缘节点加速
   
  ✓ ESA 边缘函数
    - 所有后端业务逻辑全部托管到Edge Functions
    - 实现认证、文件管理、数据同步等核心功能
    - 集成Microsoft OAuth 2.0，支持企业级身份认证
    - Node.js环境，由全球最近节点响应请求
   
  ✓ ESA 边缘存储 (EdgeKV)
    - 文件内容存储在全球分布式的KV存储中
    - 支持高并发读写操作
    - 无需运维传统数据库
   
  ✓ 智能缓存系统
    - 多层缓存架构：浏览器本地 + 边缘节点 + 源站
    - 防止返回过期数据
    - 离线优先策略

核心技术亮点

  数据一致性保证机制
  - 基于时间戳的三层对比算法：
    * 本地文件修改时间 vs 云端文件时间
    * 选择时间更新的版本作为真实数据源
  - 文件列表实时更新：每次操作都从云端获取最新列表
  - 自动重试机制：网络失败时自动重试（最多3次）

  多层缓存与离线支持
  - 编辑时本地优先缓存，秒速打开
  - 后台异步从边缘函数同步最新版本

  安全认证
  - Microsoft OAuth 2.0
  - JWT Token管理机制

【创意卓越】

充分利用ESA边缘计算能力
- 通过全球边缘节点部署，实现极低响应延迟
- 完全无服务架构，简化了应用复杂度

视觉与交互设计
- 主页采用粒子背景动效系统：响应式粒子系统，提升视觉层次
- 流畅的交互反馈：按钮点击效果、页面过渡动画
- 暗色主题设计：保护眼睛，适合长时间使用
- 整体界面简洁现代

【应用价值】

实用性强
- 思维导图工具应用广泛：
  * 学习笔记、知识管理
  * 项目规划、需求分析
  * 团队协作、头脑风暴
  * 内容创作、写作辅助
   
- 支持实时云端同步，跨设备访问
- 支持企业OAuth登录
- 自动保存机制，数据不丢失

易于使用
- 提供预设模板，新用户可直接使用
- 游客模式可快速体验（展示用途，共享数据）
- 自动化的数据同步和缓存管理

========================================
技术栈
========================================
- 前端：Vue 3 + TypeScript + Vite
- 后端：Serverless 函数（阿里云 ESA Edge Functions）
- 存储：ESA EdgeKV（边缘存储）
- 部署：ESA Pages（全球边缘节点）
- 身份认证：Microsoft OAuth 2.0
- 编辑器核心：Mind Elixir
- 缓存层：多层智能缓存系统
